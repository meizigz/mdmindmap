# 联系线绘制

Status: resolved
Blocked by: 10, 05
Spec: [spec.md](../spec.md) §1、§9；连线绘制的细节交给实现阶段（§14）

## 要做什么

- 在 SVG 层画联系线：
  - 带方向箭头，分实线、虚线、粗线三种。
  - 可以带标签，标签加背景色描边，方便阅读。
  - 颜色用 `--mdmm-relation`。
- 路径用曲线。对长联系线尽量做简单的避让（例如从节点外侧绕行），不要求完美。
- 端点所在的节点被折叠时，联系线要么连到最近的可见祖先，要么隐藏。二选一，在本工单的 Comments 里写明选了哪个。

## 验收

- 附录 A 的样例和参考截图那张图的源文中，联系线的方向、样式和标签都正确。
- `npm run check` 通过。

## Comments

**2026-10-03 完成**（Claude）。`src/render/relations.ts`。共 8 条浏览器测试，全仓库 `npm run check` 通过（210 条测试）。验收已满足：附录 A 两份样例的联系，方向、样式（虚线、粗线）和标签都正确，起点和终点都落在节点的边上。

**端点被折叠时：选择不画**（工单要求在这里写明）。理由：如果连到最近的可见祖先，会让人误以为那个祖先就是端点。展开后联系线照常出现。

**路线怎么选**（spec §14 交给实现阶段的细节）：
- 每条联系生成几条候选曲线：向两侧弯的直连曲线；从外侧绕行（两端在同一侧时）；上下边相接（两个节点上下不重叠时）。
- 对每条候选曲线沿线取 48 个点，数它穿过了几个节点（两端节点只在离开端点后才算），选穿过最少的；一样多时选最短的。
- 用牛顿样例和 AI 实测里联系最多的三角函数导图（11 条联系）截图看过，比单一规则明显干净。仍有少数联系所有候选都要穿过一个节点（例如牛顿样例的「对比」），spec 允许这种不完美。

**其他**：
- 箭头用 SVG marker，ID 带实例序号（`mdmm-arrow-N`），同一页面的多张导图不会互相冲突。marker 用 `userSpaceOnUse`，所以粗线的箭头大小不变。
- 标签是纯文字（不解析行内 markdown），放在曲线中点，用 `paint-order: stroke` 描一圈背景色。
- 新增样式类 `.mdmm-relation`、`-dashed`、`-thick`、`.mdmm-relation-label`、`.mdmm-arrow`，都属于内部实现；颜色来自公开变量 `--mdmm-relation`。
