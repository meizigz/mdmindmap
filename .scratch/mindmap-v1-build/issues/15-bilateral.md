# bilateral 结构与 setLayout

Status: resolved
Blocked by: 10
Spec: [spec.md](../spec.md) §1、§6、§7 第 3 条

## 要做什么

- bilateral 结构：用排版包装层的左右分配。左侧的分支、概要括号、下划线和连线全部镜像。
- `setLayout(layout)`：切换时保留折叠状态，并重新 fit。

## 验收

- 几何断言：左侧节点都在根的左边；左侧的概要括号朝左；切分点不在概要范围内部。
- `npm run check` 通过。

- **`setLayout(layout)`**：保留折叠状态和元素、尺寸缓存，重新排版后 fit，返回 Promise。spec §6 的接口里已有这个方法。
- **几何断言**（验收要求）：
  - 左侧分支的所有后代都在它左边。
  - 左侧概要括号在被括兄弟的左边，概要节点又在括号左边。
  - 左侧节点的折叠按钮在节点左边。
  - 左侧的下划线式节点，连线接在下划线的右端。
  - 根节点上的概要不会被切到两边。
  - `setLayout` 来回切换后，折叠的节点仍然折叠。

- **左右分配**仍然是「按可见子树的节点数均分，切分点不落在概要范围内部」（spec §14 交给实现阶段）。折叠或展开后会重新分配。
