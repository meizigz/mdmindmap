# update() 增量更新

Status: resolved
Blocked by: 13
Spec: [spec.md](../spec.md) §6、§8「update() 增量更新」

## 要做什么

- 节点身份 = 从根到该节点的文字路径。路径和文字都没变的节点，复用元素和尺寸，只测量新增或改动过的节点。
- 新画面画好之前，旧画面一直保留，不闪烁。
- 更新后，按离视口中心最近的节点重新对齐视口，用它的左侧中点对齐，缩放不变。折叠状态按路径保留。

## 验收

- 浏览器模式测试：改了一个节点的文字后，只重新测量这一个节点；视口锚点节点的屏幕坐标偏差 ≤ 1 px；折叠状态保留。
- `npm run check` 通过。

## Comments

**2026-10-03 完成**（Claude）。共 7 条浏览器测试，全仓库 `npm run check` 通过（246 条测试）。验收已满足：
- 改一个节点的文字后，其余节点复用原来的 DOM 元素（对象相同，说明没有重新测量），只有改过的节点换成新元素。
- 锚点节点的屏幕坐标偏差小于 1 px，缩放不变。
- 折叠状态得到保留。

**实现中做出的决定**：
- **节点身份**：从根到节点的文字路径。概要节点和普通子节点加了不同的前缀；同一父节点下文字相同的兄弟，按出现顺序编号。
- **复用的条件（签名）**：身份路径相同，而且颜色、是否概要、是否下划线式都相同。spec §7 的尺寸缓存键「内容 + 样式类」就是用这个签名实现的。复用的元素会更新 `data-line` 和元素到节点的映射，所以行号会随源文变化。
- **折叠状态**：同一路径的节点沿用原来的运行时折叠状态。如果源文里这个节点的 `<!-- fold -->` 标记被加上或去掉了，就以源文为准（用户改标记是有意为之）。新出现的节点按源文的标记决定。
- **锚点**：更新前离视口中心最近的节点（按盒子中心算）。更新后按它的**左侧中点**对齐（「实时预览」工单里发现，用左上角对齐会漂移），缩放不变。如果锚点节点被删掉了，视口保持不动。折叠和展开现在也按左侧中点对齐。
- **不闪烁**：新节点在离屏容器里测量，测量期间旧画面一直保留，排版完成后一次性替换。
- **诊断**：每次更新都重新生成角标和列表，并同步调用 `onDiagnostics`（更新是异步的，这时调用方早已拿到实例）。改成一个节点都没有时，清空画布并显示错误面板；之后改回来，按首次显示的规则摆放视口。
- 连续调用 `update()` 会和折叠、`setLayout` 等操作一起排队执行，不会交错。
