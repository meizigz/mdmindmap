# 牛顿运动定律

- 牛顿第一定律 ^law1
  - 惯性：物体保持原有运动状态的性质

- 牛顿第二定律 🔴 ^law2
  - { $F=ma$
  - $a$ 由合外力决定，与 $m$ 成反比
  - } 定量关系
  - 注意：$F$ 指合外力
  - { 同向性：$a$ 与 $F_合$ 方向相同
  - 瞬时性：$a$ 与 $F_合$ 同时变化
  - 独立性：各分力独立产生加速度
  - } 三性
    - 解题先做受力分析
    - 正交分解 $F_x=ma_x$
- 牛顿第三定律 ^law3
  - { 等大、反向、共线
  - 作用在两个物体上
  - 同时产生、同时消失
  - } 与平衡力的区别
    - 平衡力作用在同一物体上 ^balance
- 应用 <!-- fold -->
  - [[连接体问题]]
  - 超重与失重
  - 传送带与板块模型

%%
