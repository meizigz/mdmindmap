# md-mind-ext

A library that renders a mind map from a lightweight Markdown-based source, read-only, reusable in web apps and as an Obsidian plugin.

## Language

**Mind map (导图)**:
A tree of **Nodes** rendered from a **Source**, optionally decorated with **Summaries** and **Relationships**. Always a tree underneath: no node has more than one parent.
_Avoid_: graph, diagram, flowchart

**Source (源文)**:
The Markdown text a mind map is rendered from; either a fenced `mdmindmap` code block or a whole `.md` file. The only way to author a mind map — there is no visual editing. Usually generated by an AI first, then hand-tuned.
_Avoid_: DSL file, data

**Node (节点)**:
One topic in the mind map tree, with exactly one parent (except the root).
_Avoid_: topic, item

**Root (根节点)**:
The single top **Node** of a **Mind map**. In a whole-file **Source** it is the file's only level-1 heading when everything else sits under it; otherwise the file name stands in as the Root.
_Avoid_: title, center

**Node ID (节点ID)**:
An optional author-given identifier on a Node, written as an Obsidian-style block id (`^id`, letters, digits and `-` only) at the end of the node line. The only way a **Relationship** refers to a Node; inside the relationship section it is written bare, without the `^`.
_Avoid_: anchor, key, ref

**Summary (概要)**:
A brace that groups a run of **consecutive sibling** Nodes under the same parent and adds a summary Node beside them; the summary Node may have its own children. Cannot span different parents or non-adjacent siblings.
_Avoid_: merge, convergence, group

**Relationship (联系)**:
A directed line drawn from one Node to any other Node, overlaid on the tree, optionally carrying a text label and a line style. Does not change the tree structure.
_Avoid_: link, edge, connection

**Preset color (预设颜色)**:
One of seven named colors (red, orange, yellow, green, blue, purple, gray) an author may mark a **Node** with to highlight it. Carries no meaning of its own; it only changes how the Node looks.
_Avoid_: tag, category, priority

**Layout (结构)**:
The overall direction a mind map grows in. Two exist: **logic** (grows to the right, as in a logic chart) and **bilateral** (grows to both left and right of the root).
_Avoid_: mode, style, theme

## Relationships

- A **Mind map** has exactly one root **Node**
- A **Summary** belongs to one parent **Node** and covers one or more of its consecutive children
- A parent **Node** may have several **Summaries**; their ranges never overlap and never nest
- A **Relationship** references its two ends by **Node ID**; all Relationships are declared together in one section at the end of the **Source**
- A **Relationship** connects any two **Nodes**, including across branches; cross-branch convergence is expressed only this way

## Flagged ambiguities

- "几个节点重新聚合然后又延展" was resolved to mean **Summary**, not true multi-parent convergence (DAG). DAG layouts are out of scope.
