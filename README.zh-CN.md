# MD Mindmap

[English](README.md)

用 Markdown 标题和列表渲染只读思维导图，支持概要括号、跨分支联系、节点颜色和公式。

源文就是普通的 Markdown，没装插件时也是一份能读的大纲。设计上的主要写法是：先让 AI 生成，再自己微调。

> 状态：v0.x，开发中，还没有提交到社区插件列表。

## 怎么写

把导图写在 `mdmindmap` 代码块里：

````markdown
```mdmindmap
# 牛顿运动定律

- 牛顿第一定律 ^law1
  - 惯性：物体保持原有运动状态的性质
- 牛顿第二定律 🔴 ^law2
  - { $F=ma$
  - $a$ 由合外力决定
  - } 定量关系
- 应用 <!-- fold -->
  - [[连接体问题]]

%%
law1 -.->|合力为零时的特例| law2
%%
```
````

| 元素 | 写法 |
|---|---|
| 节点 | `#` 标题和 `-` 列表，每深一级缩进 2 个空格。只能有一个根。 |
| 概要 | 在被括住的第一个兄弟前加 `{ `，在最后一个兄弟之后另起一行同级的 `- } 总结文字`。总结节点下面还可以有子节点。 |
| 联系 | 写在源文最末尾的 `%%` … `%%` 块里：`起点 --> 终点`，`-.->` 虚线，`==>` 粗线，可以加 `\|标签\|`。两端写节点ID。 |
| 节点ID | 写在节点行最末尾的 `^id`（英文字母、数字和 `-`）。 |
| 颜色 | 行尾放一个色块 emoji：🔴 🟠 🟡 🟢 🔵 🟣 ⚫。 |
| 默认折叠 | 行尾写 `<!-- fold -->`。 |
| 行内写法 | `**粗体**`、`*斜体*`、`~~删除线~~`、`` `代码` ``、`==高亮==`、`$公式$`（含 `\ce{}` 化学式）、`[[双链]]`、`[文字](网址)`。 |

完整规则写在给 AI 看的写作说明 [`ai-guide.md`](packages/mdmindmap/ai-guide.md) 里。命令「复制 AI 写作说明」会把它复制到剪贴板，粘贴给聊天中的 AI 即可。

在命令行里校验源文（也方便 AI 自己检查）：`npx mdmindmap check <文件>`。

## 在 Obsidian 里使用

- **代码块**在阅读视图和实时预览里都会渲染。先点一下导图激活，之后滚轮缩放、拖动平移，触屏上双指缩放；点导图外面或按 Esc，滚动就交还给笔记。
- **点节点**跳到源码中对应的行；**右键或长按**节点可以复制节点文字。
- **折叠**：点分支末端的小按钮，上面的数字是被折叠的节点数。
- **整篇笔记看成导图**：运行命令「以导图打开当前文件」，或者用文件菜单。任何 `.md` 都可以；笔记里唯一的一级标题就是根，否则用文件名作根。在分屏里编辑这篇笔记，导图会跟着刷新。
- **工具栏**（嵌入导图的右上角）：在新标签页里单独打开这张图，或者导出 PNG / SVG 到附件文件夹。
- 源文有问题时，导图角落会显示 ⚠ 角标，点开可以看到改法。

颜色跟随主题。想改样式，可以写 CSS 代码片段，见下面的「样式」。

## 样式

外观全部由 `--mdmm-*` CSS 变量决定，另外有三个稳定的属性可以用来写选择器：`data-depth`、`data-color`、`data-summary`。代码片段示例：

```css
/* 红色节点改成实心红底白字 */
.mdmm-node[data-color="red"] {
  --mdmm-color-fill-amount: 100%;
  color: white;
}

/* 节点更宽一些再折行 */
.mdmm {
  --mdmm-node-max-width: 320px;
}

/* 联系线改成橙色 */
.mdmm {
  --mdmm-relation: var(--color-orange);
}
```

完整的变量清单见[核心库的说明](packages/mdmindmap/README.zh-CN.md#css-变量)。

## 已知限制

- 代码块里的双链不进 Obsidian 的索引（没有反链，改名时不会更新）。整篇笔记看成导图时，双链就是普通的链接。
- iOS / iPadOS 还没有测试。
- 不能在导图上编辑，改导图只能改 Markdown 源文。
