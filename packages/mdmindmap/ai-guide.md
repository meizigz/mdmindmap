# mdmindmap 思维导图写作说明（给 AI）

你要写的是 **mdmindmap 源文**：一种用 Markdown 写思维导图的格式。插件会把它渲染成导图；没装插件时，它看起来也只是一份普通的 Markdown 大纲。请严格按下面的规则写。

## 1. 两种输出形态

- **在对话里回答**：把导图放进语言名为 `mdmindmap` 的代码块（` ```mdmindmap `），代码块外可以有简短说明。
- **写成整篇笔记文件**（例如 Obsidian 里的 `电磁感应.md`）：整个文件就是导图，**不要**再套代码块。

## 2. 节点

- 第一行写唯一的一级标题 `# 根节点`，它就是导图的中心。整张图只能有**一个**根。
- 其余节点全部用无序列表 `- `，每深一级缩进 **2 个空格**。
- 细节、例子、公式要作为**子节点**缩进到它所属的节点下面，不要和父节点平级排列。
- 一个节点只占一行，文字要简短（一般不超过 30 字），用关键词，不要写成完整段落。
- 节点文字可以用：`**粗体**`、`*斜体*`、`~~删除线~~`、`` `代码` ``、`==高亮==`、行内公式 `$...$`（LaTeX；化学式写 `$\ce{2H2 + O2 -> 2H2O}$`）、`[[双链]]` 或 `[[双链|显示文字]]`、`[文字](网址)`。
- 不要用：块级公式 `$$...$$`、表格、图片、代码块、普通段落。这些都不会出现在导图里。

## 3. 行尾标记

一个节点行的完整形态（方括号表示可选，推荐按这个顺序写）：

```
- 节点文字 [颜色] [<!-- fold -->] [^id]
```

- **节点ID** `^id`：只在需要被「联系」引用的节点上加，必须放在行的**最末尾**。只能用英文字母、数字和连字符 `-`（例如 `^law2`、`^redox-def`），**不能用中文**，全文不能重复。
- **颜色**：在文字后面放一个色块 emoji，只能是这 7 个之一：🔴 红 🟠 橙 🟡 黄 🟢 绿 🔵 蓝 🟣 紫 ⚫ 灰。只给少数重点或易错节点加。不要在其他地方使用这 7 个 emoji，也不要用别的 emoji 表示颜色。
- **默认折叠** `<!-- fold -->`：放在细节很多的分支节点上，导图打开时它的子节点先收起。

例：`- 楞次定律 🔴 <!-- fold --> ^lenz`

**推荐把 `^id` 放在一行的最后**：这样在 Obsidian 里，这个节点还能被 `[[文件#^id]]` 从别的笔记引用。

## 4. 概要

概要是一个大括号，把**同一父节点下相邻的几个兄弟节点**括起来，再在括号右侧给出一个总结节点。总结节点下面还可以继续展开子节点。

写法（成对使用 `{` 和 `}`）：

1. 在被括住的**第一个**兄弟节点文字前加 `{ `（左括号加一个空格）。
2. 在被括住的**最后一个**兄弟节点之后，另起一行同级列表项 `- } 总结文字`（右括号加一个空格）。
3. 总结节点的子节点，缩进写在 `- } ...` 这一行下面。

```
- 牛顿第二定律
  - $F=ma$
  - { 同向性：$a$ 与 $F_合$ 方向相同
  - 瞬时性：$a$ 与 $F_合$ 同时变化
  - 独立性：各分力独立产生加速度
  - } 三性
    - 解题先做受力分析
```

上例中「三性」括住了同向性、瞬时性、独立性，「$F=ma$」不在范围内。规则：

- `{` 和 `}` 必须在**同一层级**（缩进相同），而且 `}` 在后。
- 只能括住相邻的兄弟；不同父节点下的节点不能括在一起。
- 同一父节点下可以有多个概要，但范围不能重叠，也不能嵌套。
- `- } ...` 这一行本身不算兄弟节点。

## 5. 联系

联系是一条从一个节点指向另一个节点的线，可以跨分支，用来表示因果、对比、引用等关系。所有联系**统一写在源文最末尾**的一个块里，前后各用单独一行 `%%` 包起来：

```
%%
lenz -->|决定方向| faraday
self-ind -.-> lenz
ohm ==> power
%%
```

- 箭头：`-->` 实线，`-.->` 虚线，`==>` 粗线；`|标签|` 可选，紧跟在箭头后面。
- 两端写节点ID，**不带 `^`**。用到的每个ID都必须在某个节点行末尾以 `^id` 的形式定义过。
- 结尾的 `%%` 之后不能再有任何内容。整篇只有一个这样的块；没有联系就整块省略。

## 6. 常见错误

**错误 1：把概要当成代码块的大括号。** 概要括住的是**兄弟节点**，`{` 和 `}` 必须和被括住的节点**同级**；不能把 `{` 写在父节点上，再把 `}` 写到子节点那一层。

错误：

```
- { 弧度与角度的关系
  - $\pi$ 弧度 $= 180°$
  - $1° = \frac{\pi}{180}$ 弧度
  - } 换算公式
```

正确（`{` 写在第一个被括住的兄弟上，`}` 与它们同级）：

```
- 弧度与角度的关系
  - { $\pi$ 弧度 $= 180°$
  - $1° = \frac{\pi}{180}$ 弧度
  - } 换算公式
```

**错误 2：同一层连续写好几个 `{`，却只写一个 `}`，或者 `- }` 后面不写总结文字。** 每个 `{` 都要配一个 `}`，`}` 后面必须有总结文字。

**错误 3：把概要当成分组工具。** 概要只用在真正需要「总结」的地方，比如把几条并列要点归纳成一句；不要用 `{ … }` 给一串子节点贴标签。要分组，就用父子层级。

**错误 4：细节写成了平级。** 错误：

```
- 低纬环流
- 赤道受热，空气上升
- 30° 附近下沉
```

正确：

```
- 低纬环流
  - 赤道受热，空气上升
  - 30° 附近下沉
```

## 7. 完整样例

```mdmindmap
# 牛顿运动定律

- 牛顿第一定律 ^law1
  - 惯性：物体保持原有运动状态的性质
  - 质量是惯性大小的唯一量度
- 牛顿第二定律 🔴 ^law2
  - { $F=ma$
  - $a$ 由合外力决定，与 $m$ 成反比
  - } 定量关系
  - 注意：$F$ 指合外力
  - { 同向性：$a$ 与 $F_合$ 方向相同
  - 瞬时性：$a$ 与 $F_合$ 同时变化
  - 独立性：各分力独立产生加速度
  - } 三性
    - 解题先做受力分析
    - 正交分解 $F_x=ma_x$
- 牛顿第三定律 ^law3
  - { 等大、反向、共线
  - 作用在两个物体上
  - 同时产生、同时消失
  - } 与平衡力的区别
    - 平衡力作用在同一物体上 ^balance
- 应用 <!-- fold -->
  - [[连接体问题]]
  - 超重与失重
  - 传送带与板块模型

%%
law1 -.->|合力为零时的特例| law2
law3 -->|对比| balance
%%
```

## 8. 特殊情况：转义

节点内容真的以 `{ ` 或 `} ` 开头时，写成 `\{ `、`\} `；行尾内容真的是 `^abc` 或色块 emoji 时，在前面加反斜杠：`\^abc`、`\🔴`。

## 9. 写完自查

- 只有一个 `# ` 一级标题，其余都是缩进 2 空格的 `- ` 列表。
- 每个 `{ ` 都写在被括住的第一个兄弟上，并有同一层级、在它之后的 `- } 总结文字` 与之配对；`{` 从不写在带子节点的父节点上去括它的子节点。
- 联系两端写的都是已定义的ID，不是节点文字。
- 联系块里的每个ID都已在节点行末尾用 `^id` 定义，ID 只含英文字母、数字和 `-`，且没有重复。
- 联系块在最末尾，两端写的是不带 `^` 的ID，结尾 `%%` 之后没有内容。
- 对话里回答时代码块语言名是 `mdmindmap`，不是 `mindmap` 或 `markdown`；写整篇笔记文件时不套代码块。
- 如果能运行命令，用 `npx mdmindmap check <文件>` 校验，再按输出里的改法提示修改。
- 不要写成 mermaid 或 mind-elixir 的写法，例如不要用 `}:2`、`:::red`、`A --> B` 写在列表里。
